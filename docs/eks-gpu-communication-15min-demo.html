Three mechanisms, not two

  • 1NVLS over NVSwitch — what NCCL selected for this all-reduce. NVLink SHARP reduces in the switch, not as a series of GPU-to-GPU copies.
  • 2GPUDirect P2P / CUDA peer access — the generic intra-node GPU↔GPU path, over NVLink, NVSwitch or PCIe.
  • 3GPUDirect RDMA — not used here. It is the inter-node mechanism; nothing intra-node traverses a NIC.
  • nvidia-smi topo -m is the topology proof; the NCCL logs prove the software used that fabric. Two different claims.

GDRCopy failing does not mean GPUDirect RDMA failed. GDRCopy is a CPU-side BAR mapping for low-latency small copies — built on the same plumbing, but it moves nothing over the network. Bulk KV transfer is carried by provider=efa + DMA-BUF registration + the peer handshake above, none of which depend on it.

Appendix C

GPUDirect is a family, not a synonym for RDMA

Only one member moves bytes over a network. Saying “GPUDirect” when you mean GPUDirect RDMA is the most common way this stack gets misdescribed. Vendor documentation, not lab evidence

Member, as NVIDIA names itWhat it doesUses RDMA?
GPUDirect RDMAA third-party PCIe peer — NIC, storage adapter, capture card — reads and writes GPU memory through a PCIe BAR window. Peers must share the same upstream PCIe root complex.Yes
GPUDirect Peer to PeerGPU-to-GPU copies, and direct loads and stores, over the memory fabric — PCIe or NVLink.No
GPUDirect StorageStorage I/O directly between storage and GPU memory. Local NVMe can use PCIe P2PDMA when supported; distributed filesystems such as Lustre, WekaFS, and NFS can use RDMA-capable GDS paths.Depends
GPUDirect for VideoLow-latency frame exchange with video I/O devices.No
GDRCopy (not a family member)A CPU-side mapping of the GPU BAR for low-latency small copies. Built on GPUDirect RDMA plumbing, but the window goes to the CPU and no network transfer occurs.No

EFA’s RDMA rides SRD, not RoCE or InfiniBand. SRD is an Ethernet-based transport that deliberately relaxes in-order delivery, re-asserting order higher in the stack. It sprays a block across many paths — 64 at a time, chosen from hundreds or thousands — so a single lost packet causes no head-of-line blocking. AWS reports p99 tail latency falling roughly 10× versus in-order transports.

RDMA does not mean “no CPU”. As the lab’s own concepts doc puts it: “‘GPU bypasses the CPU’ is shorthand, not literal.” The CPU still creates connections, registers memory, exchanges metadata and launches kernels. Only the bulk payload avoids host-memory copies.

  • This lab measured GPUDirect RDMA over EFA and observed NCCL/NVLS over NVLink and NVSwitch intra-node. It did not independently exercise the GPUDirect Peer-to-Peer API. GPUDirect Storage was not exercised — FSx for Lustre carried model and dataset I/O as an ordinary mount.
